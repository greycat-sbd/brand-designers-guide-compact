# Бренд-дизайн: рабочий маршрут

Рабочие материалы к краткой практической версии книги Влада Попова.

Книга проводит по основному маршруту бренд-проекта: от постановки задачи и чтения категории до визуальной системы, работы с правками и проверки перед запуском. Этот репозиторий дополняет книгу файлами, которые можно использовать в реальном проекте.

## Два шаблона для начала работы

### 1. Карта бренд-проекта

Помогает собрать на одной странице контекст, бизнес-задачу, аудиторию, ситуацию выбора, конкурентов, ограничения и критерии проверки.

- [Открыть версию Markdown](brand-project-map.md)
- [Скачать редактируемый DOCX](brand-project-map.docx)

### 2. Протокол правок

Отделяет фактическую ошибку от изменения задачи, вкусового мнения и симптома более глубокой проблемы. Фиксирует решение, последствия, ответственного и статус.

- [Открыть версию Markdown](revision-protocol.md)
- [Скачать редактируемый DOCX](revision-protocol.docx)

## Как пользоваться шаблонами

1. Скопируйте Markdown-файл или скачайте DOCX.
2. Заполняйте только то, что известно. Неясные пункты отмечайте как «не хватает данных».
3. Храните заполненную версию рядом с брифом, макетами и протоколами согласования.
4. Если меняется исходная задача, не маскируйте это под обычную правку: обновите рамки проекта отдельно.
